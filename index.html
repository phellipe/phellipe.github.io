01Sobre

Engenheiro full-stack e ex-líder de TI.

Sou João Phellipe, engenheiro de software em Mossoró (RN). Me formei em Ciência da Computação, fiz mestrado em Sistemas Computacionais na UFERSA e hoje curso um doutorado na área de educação.

Passei mais de uma década dentro dos sistemas de larga escala de uma universidade federal, entre eles os sistemas integrados de gestão (SIG), código Java de grande porte que mantenho e evoluo até hoje. Por quatro desses anos fui Superintendente de TI, respondendo por infraestrutura, sistemas, governança, segurança da informação e equipes. É essa bagagem de arquitetura e gestão que levo para construir produtos full-stack em monorepos TypeScript: React e React Native na interface, Node e PostgreSQL por trás, Docker e CI/CD para colocar tudo em produção.

Já resolvi o que costuma assustar um time: vídeo em tempo real com WebRTC, assinatura digital ICP-Brasil (incluindo um helper A3 para desktop escrito em Rust), sistemas multi-tenant isolados com Row-Level Security no Postgres e um agente de IA atendendo clientes de verdade no WhatsApp. Entrego sozinho ou liderando equipe, e não abro mão de testes nem de acessibilidade. Nas horas vagas, mantenho um clone de River Raid escrito em C com SDL2, com todo o som sintetizado em código.

03Trabalhos

Trabalhos selecionados.

Alguns dos sistemas que construí ou venho construindo nos últimos anos. Boa parte está sob NDA, então descrevo pelo domínio, sem citar clientes.

  1. 01

    Plataforma de telemedicina

    Agendamento, videoconsulta, prontuário eletrônico e emissão de receitas e atestados com assinatura digital ICP-Brasil (A1, A3 e nuvem). Vídeo com WebRTC em infraestrutura própria, com Jitsi e servidor TURN self-hosted, e um helper de assinatura A3 para desktop que reescrevi de Electron para Rust.

    • React
    • Node
    • PostgreSQL
    • WebRTC
    • Rust
    • Docker
  2. 02

    Agente de IA para vendas no WhatsApp

    SaaS em que um agente de IA atende leads no WhatsApp, qualifica a conversa e passa o cliente quente para o vendedor humano. Estou reconstruindo como aplicação própria a plataforma, que rodava em ferramentas no-code: painel admin, planos e controle do custo de IA por vendedor.

    • NestJS
    • PostgreSQL
    • OpenAI
    • WhatsApp
    • Docker
  3. 03

    Plataforma educacional (web + mobile)

    Gestão escolar, trilhas de aprendizagem com correção automática, gamificação e comunicação escola-família, na web e no celular. São seis perfis de usuário, um banco com mais de 50 tabelas e um tutor de IA. Alinhada à BNCC e à LGPD, com acessibilidade levada a sério.

    • React
    • React Native
    • Fastify
    • tRPC
    • Drizzle
  4. 04

    ERP financeiro SaaS

    Plano de contas, DRE, fluxo de caixa, vendas, comissões e estoque para PMEs. Multi-tenant com Row-Level Security no Postgres, SDK TypeScript gerado do OpenAPI e importação de extratos que reconhece o layout de cada banco.

    • Next.js
    • NestJS
    • Drizzle
    • PostgreSQL
  5. 05

    Plataforma SaaS de factoring

    Plataforma multi-tenant para empresas de fomento mercantil, com portal do cedente e billing próprio (planos, medição de uso, fatura calculada). Isolamento por tenant com Row-Level Security no Postgres e deploy self-hosted com Docker.

    • NestJS
    • Next.js
    • Prisma
    • PostgreSQL
  6. 06

    App de finanças pessoais offline-first

    App mobile que responde uma pergunta só: quanto sobra no fim do mês? Os dados ficam em SQLite no aparelho e passam por uma fila de sincronização até o backend, um Supabase self-hosted. A lógica de domínio vive num pacote TypeScript puro com 100% de cobertura de testes.

    • React Native
    • Expo
    • SQLite
    • Drizzle
  7. 07

    Sistemas para o setor jurídico

    Gestão e automação para escritórios de advocacia, cobrindo processos, demandas em Kanban, audiências e clientes. A calculadora de prazos sabe a diferença entre CPC e CPP, dobra prazos para a Fazenda Pública, busca feriados na BrasilAPI e valida número CNJ. Permissões granulares e auditoria de cada operação.

    • React
    • tRPC
    • Drizzle
    • PostgreSQL
  8. 08

    Notificações via Telegram para sistemas universitários

    Microserviço que avisa a comunidade de uma universidade federal no Telegram: nota lançada, ponto, férias, andamento de processo. Os sistemas legados em Java gravam o evento numa outbox transacional no Postgres; o serviço lê via LISTEN/NOTIFY, checa o consentimento (LGPD) e envia pelo bot.

    • Node
    • TypeScript
    • PostgreSQL
    • Java
    • Telegram
  9. 09

    Avaliação de carreira no setor público

    Servidores de uma universidade federal submetem processos de Reconhecimento de Saberes e Competências: editais com regras de pontuação configuráveis, avaliação por comissão e cálculo automático da nota, com leitura direta do banco dos sistemas acadêmicos (SIG). Em produção, com manuais de usuário publicados.

    • NestJS
    • Next.js
    • Prisma
    • PostgreSQL

    Indicadores com séries históricas e projeção de metas para secretarias municipais de educação, planos de ação com semáforo de custo, prazo e escopo, e perfis para secretaria, gestores e diretores. Web e mobile.

    • Recharts

    Ecossistema digital para indústria de alimentos

    Site institucional em três idiomas, painel de gestão, portal B2B e API central para uma indústria de alimentos, num monorepo com cinco aplicações que já inclui a base do marketplace B2C. Rastreabilidade da produção e geração de catálogos e documentos de exportação em PDF.

    • Next.js
